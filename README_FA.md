# پنل اضافه‌کاری اندروید — نسخه ۲.۱۳

این پروژه WebView آفلاین است و فایل HTML پنل در `app/src/main/assets/index.html` قرار دارد. داده‌ها و تنظیمات داخل فضای ذخیره‌سازی محلی WebView ذخیره می‌شوند؛ پاک‌کردن داده برنامه یا حذف نصب می‌تواند آن‌ها را حذف کند. برای اعلان و صدای یادآور، برنامه باید در حال اجرا باشد؛ زمان‌بندی پس‌زمینه هنگام بسته‌بودن کامل برنامه تضمین نشده است.

## ساخت با GitHub Actions
1. کل پوشه پروژه را در یک مخزن خصوصی GitHub بارگذاری کنید.
2. طبق `SIGNING_SETUP_FA.md` چهار Secret امضای ثابت را اضافه کنید.
3. از Actions، workflow با نام **Build Android APK** را اجرا کنید.
4. از خروجی اجرا، Artifact با نام `overtime-panel-debug-apk` را دانلود کنید.

**مهم:** کلید `.jks` و فایل رمزها را commit نکنید. قبل از نصب روی نسخه قدیمی، اثرانگشت گواهی را مقایسه کنید.


## ویجت صفحه اصلی اندروید (نسخه ۲.۱۸)
پس از نصب APK، روی صفحه اصلی گوشی لمس طولانی کنید، بخش «ویجت‌ها» را باز کنید و «جمع اضافه‌کاری» را به صفحه بکشید. برای همگام‌شدن مقدارها، برنامه را باز کنید؛ با هر بار به‌روزرسانی محاسبات در برنامه، ویجت نیز تازه می‌شود. ویجت بومی فقط در نسخه اندروید قابل افزودن است، نه در فایل HTML مرورگر. در این نسخه، نام کاربران و رکوردهای ساعت ذخیره‌شده قبلی یک‌بار پاک می‌شوند تا ورود اطلاعات از نو انجام شود.
