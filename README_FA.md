# پنل اضافه‌کاری — نسخه 1.1

## امکانات این نسخه
- رابط بازچینی‌شده با نوار ابزار شناور پایین صفحه
- انتقال تنظیمات شیفت، تغییر تم، ذخیره فایل، پشتیبان‌گیری، بازیابی و چاپ به نوار ابزار
- حذف گزینه «افزودن به صفحه اصلی» و دکمه داشبورد از نوار کناری
- انتقال دکمه‌های ثبت ورود و ثبت خروج به زیر اطلاعات پرسنل
- انتقال انتخاب بازه تاریخ به کنار عنوان گزارش ماهانه
- لوگوی داخل برنامه و آیکون اختصاصی لانچر اندروید
- ذخیره و پشتیبان‌گیری با پنجره انتخاب محل ذخیره اندروید؛ بازیابی با انتخاب فایل JSON
- چاپ از طریق سرویس چاپ اندروید
- هدف Android API 35 برای سازگاری با نسخه‌های جدید اندروید

## ساخت APK در GitHub
1. تمام محتویات این پوشه را در ریشه مخزن GitHub آپلود کنید؛ پوشه مخفی `.github` هم باید آپلود شود.
2. فایل `.github/workflows/build-apk.yml` باید در همین مسیر باشد.
3. از تب Actions گردش‌کار `Build Android APK` را اجرا کنید.
4. پس از موفقیت، از بخش Artifacts فایل `overtime-panel-debug-apk` را دریافت کنید؛ داخل ZIP دانلودشده، فایل `app-debug.apk` قرار دارد.

## نکته نصب
این نسخه برای Android API 35 ساخته می‌شود تا خطای «برنامه برای نسخه قدیمی اندروید ساخته شده» برطرف شود. اندروید ممکن است برای نصب APK خارج از فروشگاه همچنان تأیید نصب از منابع ناشناس یا هشدار Play Protect نشان دهد؛ این هشدار با بالا بردن target SDK الزاماً حذف نمی‌شود.

## ذخیره‌سازی
فایل‌های خروجی و پشتیبان JSON هستند. برای انتقال اطلاعات، در برنامه پشتیبان بگیرید و در دستگاه مقصد از گزینه بازیابی استفاده کنید. محاسبات در خود پنل انجام می‌شود؛ دریافت تعطیلات رسمی به اینترنت نیاز دارد.
